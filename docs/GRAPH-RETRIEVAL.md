# 图记忆检索实验

`memory.rankedRecall: true` 只替换图节点候选检索，不改变图扩散、卡片选择或原文跨度检索。没有足够图命中时，`soul_recall` 仍可回查原文：图层空结果不是整个工具的拒答。无需外部服务或模型。首次启用会从现有节点构建索引；关掉后读路径恢复，已建索引继续同步写入。磁盘与写入开销见下。

实现参考 [BEIR 论文](https://arxiv.org/abs/2104.08663)、[BEIR 开源评测](https://github.com/beir-cellar/beir) 与 [SQLite FTS5](https://sqlite.org/fts5.html)。索引沿用现有去重词项和中文二元词，因此不是对原始文本做标准 BM25。BM25 生成短名单，最终顺序还考虑查询覆盖率，以及覆盖相同时的有效期。含完整路径的查询须匹配路径，而非仅仅文件名；无实例锚点的查询要求至少半数查询词重合。阈值是可检验的工程假设，不是论文给出的通用最优值。

## 复现

```sh
node bench/forgetting.mjs --days=90 --cap=100 --seed=53 --tiered --compare-retrieval --json
```

`report.auto.paired` 是自动维护下的只读对照。每次正负查询都比较两种算法，包括卡片已经有答案的查询；交替执行顺序，不把对照命中写回图。默认用旧检索推进会话；加 `--ranked` 则用新检索推进。计时只覆盖候选查询，不包含建索引、图扩散、卡片或宿主开销。

| 天数 / 种子 | 前三有正确答案，旧 → 新 | 无答案时图层返回空，旧 → 新 | 候选查询 P95（ms），旧 → 新 |
|---|---:|---:|---:|
| 42 / 7 | 40 → 47 / 47 | 0 → 14 / 14 | 5.18 → 0.74 |
| 90 / 53 | 80 → 108 / 108 | 0 → 30 / 30 | 5.05 → 0.91 |
| 90 / 71 | 76 → 108 / 108 | 0 → 30 / 30 | 5.00 → 0.93 |

本机内存数据库、非置顶总量上限 400，时间仅供量级参考。正例用同一生成器并含实例名；负例来自重复的六种问法，不是 74 个独立意图。不能据此声称真实准确率为 100%。默认暂不开启，下一轮应盲测真实中文改写、缺少实体的请求、已有对象的错误属性，并量化持久数据库的冷启动及写放大。

## 持久库成本

`node bench/retrieval-disk.mjs` 在本机临时目录复制同一份 1,000 节点旧库，每对实验交替先后顺序。每组逐个事务插入 100 条、修改 100 条，无淘汰。Windows、Node v24.19.0、六轮中位数：

| 指标 | 未建索引 | 首次开启 FTS5 |
|---|---:|---:|
| 打开已有数据库（含首次建索引） | 8.64 ms | 13.37 ms |
| 200 次写入总耗时 | 710.43 ms | 724.25 ms |
| checkpoint 后的数据库 | 912 KiB | 1068 KiB |
| 写入期间 WAL 文件 | 8.31 MiB | 13.06 MiB |

未清操作系统缓存，不是冷盘延迟。为单独观测 WAL 增长，两组写入时均关闭自动 checkpoint；其大小不是正常运行时的常驻空间，也不是 SSD 物理写入量。脚本输出逐轮数值，时间差异仅描述本机样本。

## 真实查询盲测

运行 `node bench/retrieval-holdout.mjs labeled.json`。以下仅是格式示例，不是真实评测数据：

```json
{"snapshots":[{"nodes":[{"id":"n1","claim":"发布前要先生成校验文件","seen":100}],"queries":[{"id":"q1","text":"当时说上线之前要补的东西是什么？","gold":["n1"]},{"id":"q2","text":"这次要找谁签字？","gold":[]}]}]}
```

每个快照只含提问当时已经存在的脱敏节点。优先导出 `seen`、`state`、`valid_to`、`kind`、`pin`；缺少 `seen` 时按输入顺序从旧到新。`gold` 是人工事先标注的所有可接受答案节点；只有确认图中没有答案时才填 `[]`，不确定的题单列待审。应在看两组排序之前冻结标注，覆盖无标识符改写、相似对象、错误属性和过期事实。调过阈值后用另一批会话验证，不重复把同一批称为盲测。

输出带输入文件指纹、前三命中/正确返回空的分子和分母，以及逐题得失；不输出问题或节点正文。只比较节点候选，不代表模型最终作答。当前仓库没有人工标注的真实会话集，本轮不报告真实准确率。
