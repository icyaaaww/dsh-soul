# 骨架压缩：实测

`bench/compaction-loss.mjs` 测量的是**选择策略**的损失，不是某个摘要器的损失。三个策略看同一份历史、同一个字节预算，只改变"什么活下来"。

~~~powershell
npm run bench                 # 默认 1200 bytes
node bench/compaction-loss.mjs --budget=600 --sample
~~~

## 方法

- 300 个确定性场景，每个约 7 KB / 68 个块，任务开始处有 3 条硬约束（真实会话里约束总在最前面，也总最先被压掉）。
- 11 个"必须记得"的记忆项：3 约束、2 决策、3 产物、1 进度、2 条只出现在工具输出里的环境事实。
- 三种策略，预算相同：
  - **窗口截断**：从最新往回装，最老的先丢。
  - **摘要替代**：保尾部、按 4→2→1 的步长均匀采样其余部分，每块截到 60 字。采样密度随预算增加，**这是对基线有利的设置**。
  - **骨架选择**：`src/skeleton.js` 的 `compact()`。
- 指标：记忆项的字面量是否还在最终上下文里；`约束保留` 是其中 3 条的子集；`可续跑` 要求 3 个关键 token 同时在场。

## 结果

| 预算 | 策略 | 细节保留 | 约束保留 | 可续跑 | 实际字节 |
|---|---|---|---|---|---|
| 600 | 窗口截断 | 15.3% | 0% | 0% | 438 |
| 600 | 摘要替代 | 16.7% | 0% | 0% | 607 |
| 600 | **骨架选择** | **45.5%** | **100%** | 0% | 570 |
| 1200 | 窗口截断 | 25.5% | 0% | 0% | 1062 |
| 1200 | 摘要替代 | 43.2% | 33.3% | 0% | 1220 |
| 1200 | **骨架选择** | **83.4%** | **100%** | **100%** | 1161 |
| 2400 | 窗口截断 | 41.1% | 0% | 0% | 2295 |
| 2400 | 摘要替代 | 86.8% | 100% | 100% | 2439 |
| 2400 | 骨架选择 | 84.1% | 100% | 100% | 2197 |

1200 bytes（约历史的 17%）时，相对窗口截断：细节保留 **25.5% → 83.4%**，损失率 **74.5% → 16.6%**。

## 三条结论

1. **优势来自压缩比，不来自绝对质量。** 预算 2400（约历史的 34%）时均匀采样反超骨架（86.8% vs 84.1%）——东西装得下的时候，选不如全留。骨架只在**压得很狠**的时候有价值，这正好是压缩发生的场合。
2. **约束是零成本的胜利。** 三个预算下骨架都是 100%，另两个基线在 1200 及以下都是 0%。这不是算法变强了，是 `pin` 把它挪出了竞争。
3. **600 bytes 是个断崖。** 固定 45% 的节点份额被 3 条约束吃掉，剩下的钱不够把任务线接上，`可续跑` 归零。低于 ~800 字节时需要弹性分配（P2）。

## 局限（必读）

- **`摘要替代` 不是 LLM。** 它是"保尾部 + 均匀采样"的确定性替身，用来给另外两个策略一个中点。真实模型摘要的表现另见 Compact-Bench（重复细节保留 ≤16%），不要在论文里把这里的数字当成 LLM 基线。
- **11 个记忆项里有 9 个是可抽取的**——这正是架构的主张（约束/决策/产物/进度应当结构化），但也意味着 83.4% 里有一部分是"抽取对了"，而不是"选对了"。真正考验选择的是那 2 条环境事实，骨架只拿到 17.7% 和 0%，这就是残余损失。
- **没有失效、没有跨会话、没有并发。** `hash` 失效判定有单测覆盖（`tests/skeleton.test.mjs`），但没有进基准。
- **场景是合成的。** 真实会话的块更长、噪声更杂，绝对值会变，排序不一定。

## 与 1.6 的关系

1.6 的压缩后端（`dsh-soul/compaction`）调用的就是这里的 `compact()`，所以上面的数字是**线上路径**的估计，不是离线玩具。差别只有一处：后端把预算定在跨度的 20%（600–3000 字节），而不是固定 1200。

## 单测

`tests/skeleton.test.mjs` 10 项：句号不切 `package.json`、决策不重复生成进度节点、改同一文件产生 `supersedes`、PPR 是分布、预算不超、失效产物被扣留、空历史不炸。
