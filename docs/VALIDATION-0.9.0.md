0.9 的 paired replay 比较从演化启动时固定的已提交状态开始，不是原始在线任务完整环境的重建。验收保护依赖用户声明全部测试/配置依赖；指纹不是 OS 级隔离。C7 仅支持纯 JSON 转换，C8 仅支持工具执行后的建议反馈。
