## 原版验证记录与迁移更新

- npm run check：81 项测试，80 通过，0 失败，1 跳过（真实 DSH 宿主测试需要 DSH_TEST_PACKAGE）。
- npm run demo：确定性成对探测、shadow、真实纠正触发的回滚与账本完整性检查通过；contrast 作为普通证据文件写入，不改变采纳闸门。演示还用两次措辞不同的“工具错误后恢复”确认经验池零模型调用、聚成 support=2 的单簇并显示编译资格与已观察成本。
- 经验分类：普通干净回合不记录；用户纠正、工具错误未完成、未完成、工具错误后恢复分别归入唯一类型；仅有同类前序分歧的干净回合才记为 resolved。
- 存储前统一 redact 用户文本与工具错误；经验 detail、divergence 与 trajectory 都不保留明文凭据。
- 词项聚类：同一任务的措辞变化合并到同一簇并增加支持度；无关任务保持分离；达到阈值转为 candidate，超过 repeatWindowDays 未再出现的簇不再进入付费候选。
- contrast：包含经验簇、当前观察、同任务成功/恢复样本三部分；不超过 3000 字节；指标渲染为 `toolErrors=N`，不内联原始轨迹 JSON。
- 编译：经验簇触发的 episode 走原编辑、结构检查、成对重跑与 shadow；shadow 失败重开对应经验并清除 rev；第二次失败退役；普通复发只增加支持度，不重开已编译经验；退役后 /evolve run 在编辑调用前拒绝。
- 被回滚的相同候选树返回 retired_revision，按 rejection 结算而不是内部失败，避免无限重试同一经验。
- /evolve verify 通过时写入 verified_success 正样本；该类型不进入可触发候选。
- 插件路径：无本地分歧时，evolve_diagnose 返回经验池，evolve_request 只返回资格；/evolve run 可以经验簇进入付费路径，但无宿主能力时在模型调用前拒绝；/evolve report 返回经验池、成本与“留存/迁移未证明”声明。
- schema 迁移：手工构造 user_version=1 的旧库，打开后升级到 3，episode 获得 lesson 列且旧记录保留。
