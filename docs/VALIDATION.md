# DSH Soul 0.2.0 验证记录

日期：2026-10-24。项目由 DSH Learning 更名为 DSH Soul。

## 已完成的本地验证

- Node 24.19.0、Windows：`npm run check` 的 45 项测试及 11 个确定性检索场景全部通过，无跳过。
- 使用实际 DSH 0.2.0-rc.2 验证命令、会话事件、上下文、工具 schema、Cordis 加载/卸载/重新加载。
- `dsh-soul-0.2.0.tgz` 使用标准 DSH plugin 命令安装到隔离 profile；安装后的入口再次通过两项真实宿主测试。
- 从已打包的 DSH Learning 0.1.0 创建旧数据库，再升级到 schema 2：记忆、来源、技能反馈、遗忘指纹和已用额度全部保留。
- 包名、bundle 插件 ID 和展示名称统一为 DSH Soul。保留 `/learn` 命令及旧数据目录以兼容现有记忆。

## 本地检索性能样本

10000 条合成记录，临时磁盘 SQLite，每类查询 100 次；Windows、Node 24.19.0、Ryzen 9 7945HX、32 GiB。

| 查询 | p50 | p95 |
|---|---:|---:|
| 具体英文标签，插件缓存未命中 | 0.148 ms | 0.203 ms |
| 宽泛中文，插件缓存未命中 | 20.436 ms | 23.690 ms |
| 重复中文查询，插件缓存预热 | 0.004 ms | 0.008 ms |

这组数据来自更名前的同一检索实现。未命中只清插件缓存，不清 SQLite/操作系统缓存；不包含网络和模型耗时，不是跨设备性能承诺。可通过 `npm run bench` 重新测量。

`npm run eval` 的长技能例子中，完整技能是 3032 字节，卡片是 220 字节；真正使用时还需要读取全文并增加一次工具往返，不能据此推算总费用降幅。

## 验证边界

- 11 个检索场景是手写回归材料，不是独立公开基准；未进行付费模型的真实任务成功率和总成本评测。
- 技能验证依据人工反馈；没有模型微调、自主源码修改或自动执行技能测试。
- GitHub CI 在 Windows/Linux 上执行离线检查；没有安装 DSH 的环境会明确跳过两项宿主集成测试。其结果以仓库 Actions 为准。
- 后台学习默认关闭，启用后需配置 provider/model；逻辑请求限额不等于货币硬上限。
- 升级前退出 DSH 并备份数据库；0.1 无法打开 schema 2，回退需要恢复旧备份。
